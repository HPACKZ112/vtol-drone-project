# Contributing

Keep each change small enough to explain and review. Use ordinary Python functions
and clear variable names with units; introduce extra tools only when needed.

1. State the engineering question or bug in an issue or decision note.
2. Document assumptions, sources, and any changes to the example inputs.
3. Add checks for new numerical behaviour, including one independently calculated
   example or a known physical trend.
4. Run the analysis and the tests shown in the README.
5. Include the result and its limitations in the pull request.

Separate assumed, simulated, and measured evidence. Record hardware configuration,
firmware version, and conditions with every test. Keep credentials and private
location data out of the repository. Record AI assistance or other external help
where it contributed to the work.
