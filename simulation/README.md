# Dynamics simulation

The Python sizing models are in `analysis/`; they are not a flight simulator.
There is no dynamics or transition model in this folder yet.

After choosing a layout, select an established dynamics/autopilot simulation
environment and document geometry, mass/inertia, aerodynamics, propulsion, and tilt
actuation. Define hover, transition, cruise, and failure scenarios before recording
results. A complete simulation must address rotor/wing interaction and control
authority that the preliminary sizing equations omit.
