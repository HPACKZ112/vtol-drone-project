# Future Python measurement tools

Use `analysis/` for current calculations. This folder is reserved for later Python
tools that process real propulsion measurements or flight logs.

Keep raw records separate from processed outputs. Document units, timestamps,
sampling, filtering, uncertainty, and the instrument or log format. Begin with
small functions and CSV files; add NumPy or pandas when the data requires them.
No telemetry or flight-log processing tool is included yet.
